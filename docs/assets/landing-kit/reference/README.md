# Extracted reference assets

These are exact crops from the three user-supplied visual collection boards, kept here so future
landing work does not need to reopen and recrop the boards.

- `source-boards/` preserves all three original collection images verbatim.
- `modules/board-01`, `modules/board-02`, and `modules/board-03` contain every numbered visual
  group from its respective board: hero art, marks, icons, frames, dividers, widgets, reliefs,
  diagrams, textures, particles, patterns, CTA treatments, ornaments, and palettes.
- `modules/board-03/small-icons/` contains the 20 compact UI symbols as individual files.

The original boards are retained as a completeness backstop; the module exports make every group
directly reusable without manually finding or recropping it.

The icon sheets and state badges are not approved for runtime use. If adopted later, they need an
accessibility review, a licence/usage-rights record, and an active specification that authorizes
the icon set. Any runtime asset must also be added to the landing route's explicit asset allowlist.
