# Khepri landing asset kit

Reusable visual source material for the public landing page. These files were selected from the
user-supplied `khepri_visual_pack` on 2026-09-01; they are not wired into the runtime yet.

## Selected assets

| Asset | Intended use |
| --- | --- |
| `hero-scene.jpg` | Wide landing hero background |
| `hero-winged-scarab.png` | Primary decorative hero emblem |
| `register-divider.png` | Section divider |
| `blueprint-*.png` | Low-opacity technical decorations |
| `texture-*.jpg` | Subtle section backgrounds |

The supplied `state-*.png` badges are deliberately excluded. They would create a new functional
icon set, which the current product rules do not yet authorize. The ornate `result-portal-frame.png`
is also excluded because it is not suitable for responsive landing content.
