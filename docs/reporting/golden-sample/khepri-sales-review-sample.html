6. What this review does not cover

Three analyses could not be produced from the file you supplied. Everything shown above is unaffected by these.

Basket size — how many items are in each sale

Your file has no receipt or invoice number, so there is no way to tell which rows belong to the same sale. Counting rows instead would overstate basket size wherever one sale spans several lines.

The rest of this review is unaffected.

To make it available: export with the receipt number included.

Comparison with the same period last year

Your file covers seven months, so the same period one year earlier is not inside it. The comparison shown above is against the seven months immediately before.

The rest of this review is unaffected.

To make it available: export a file that also covers January to July of last year.

Profit margin

No cost column was found in the file, so revenue can be measured but profit cannot.

The rest of this review is unaffected.

To make it available: include the unit cost in your export.

Qualifications on figures that are shown

The concentration curve is drawn from 100 evenly spaced points across your full product range. The figures beside it use every row.
