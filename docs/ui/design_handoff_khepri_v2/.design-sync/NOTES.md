# design-sync notes — @khepri/ds (Khepri v2)

- Source of truth for the look: `E:\Kemetra\khepri ui v.2.pdf` (10 image-only mockup pages; no text layer). The DS is authored from it — this repo *is* the component library; there is no upstream app code.
- Deliberately kept OUT of the Khepri repo: Khepri governance admits product code only in spec-linked slices.
- Build: `npm run build` = tsup (ESM JS, `dts: false`) + `tsc -p tsconfig.build.json` (declarations) + `scripts/build-css.mjs` (concats `src/styles/{tokens,base,components}.css` → `dist/khepri.css`). tsup's dts plugin crashes with the installed TypeScript 7 (`useCaseSensitiveFileNames`), hence tsc for `.d.ts`; TS 7 also requires explicit `rootDir`.
- Converter run: `node .ds-sync/package-build.mjs --config .design-sync/config.json --node-modules ./node_modules --entry ./dist/index.js --out ./ds-bundle`.
- Playwright: machine cache is `%LOCALAPPDATA%\ms-playwright\chromium-1228` → `.ds-sync` needs `playwright@1.61.0` (latest pins 1243 and fails to launch).
- Fonts: Noto Sans Arabic 400–800 (Arabic + Latin subsets) copied from `@fontsource/noto-sans-arabic` into `fonts/` with a hand-written `fonts/fonts.css` (wired via `extraFonts`). Khepri's own repo only ships the Regular weight.
- Hero art: `src/assets/khepri-hero.webp` is the governed derivative from the Khepri repo (`src/khepri/rra/journey/assets/`), inlined as a data URL. The PDF's Nile artwork has no source file and was NOT cropped from the PDF. Sidebar pyramids are a hand-drawn SVG.
- Logo: `KhepriLogo` is a simplified SVG scarab + "KHEPRI" wordmark, not the official raster logo (`E:\Kemetra\Khepri.png` is a dark-background ornate mark unsuitable for UI).
- `docs/<Name>.md` are category-only stubs (grouping); `.prompt.md` bodies are synthesized from JSDoc + props + previews. `guidelinesGlob` points at a non-existent dir on purpose (default glob would upload the stubs as guidelines).
- Charts measure their container (`useChartWidth`) so SVG text stays real-size; y-axis ticks via `niceTicks`.
- Composite components use `cardMode: "column"` — in the default multi-column grid their RTL content squeezes/clips.
- Colours were sampled from the PDF at 72dpi (JPEG noise ±5); gold/sand token names follow Khepri's shell tokens with a `--k-` prefix.
