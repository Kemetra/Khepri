5 · Decisions for the owner

  1. 1Primary button colour. The current rule is gold primary; the North Star uses ink. Confirm ink.
  2. 2Logo and wordmark. Scarab mark is unchanged; North Star uses a text placeholder.
  3. 3Exact brand values for ink, gold and paper; hex values above are working values.
  4. 4Display face. Noto Naskh Arabic for Arabic headlines, and what English headlines use.
  5. 5Digits. Western digits throughout, or Arabic-Indic as a locale option.
  6. 6Sidebar, DonutChart, ProgressRing. Retire, or keep for library and admin screens.
  7. 7Tone palette. Teal, blue, sky, purple and amber reduced to status-only use. Confirm the status colour mapping.
  8. 8Caveat and refusal. The current library has no component for these. They need their content rules defined before a visual treatment is added.
