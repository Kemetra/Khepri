# RRA-004: Deterministic Retail Fact Package

## Outcome

One immutable, versioned fact package contains every numerical claim and citation that may appear
on any report surface.

## Requirements

- Compute core KPIs when answerable: revenue, units, transactions, average order value, and
  average selling price.
- Compute gross profit and margin, discounts, and returns only when their required governed
  inputs exist.
- Apply documented zero, null, currency, sign, duplicate, return, and aggregation semantics.
- Produce governed time trends and product, category, store, and channel comparisons only when
  the relevant dimensions are admissible.
- Retain, for each admissible comparison dimension, the ranked revenue share curve over the full
  distinct-value set before display truncation, together with the distinct-value count and the
  count ranked. The curve carries shares only and no value labels.
- Retain, for each admissible comparison dimension, the count of distinct transactions per
  published bucket and the full-set distinct transaction total, when a transaction identifier is
  mapped. A row count is never a transaction count.
- Retain, for each published time bucket, the count of distinct dates the bucket covers, so a
  derived result can tell a whole period from a partial one and truncate two windows to the same
  day count.
- Record the governed comparison window length: one period at the package's own time granularity.
  A derived comparison reads its window from the package rather than choosing one, because a
  window whose length depends on how much history happens to be present is not governed.
- Record the formula version on each emitted fact as a field the serialized fact discloses, not
  only as an input to its identifier. A hashed version names a fact and cannot be read back from
  it, so a stored citation cannot otherwise state which formula produced the number it cites.
- Reconcile every aggregate to its input measure and emit a caveat or refuse the affected result
  when reconciliation fails.
- Assign stable fact and citation identifiers and record input digest, mapping version, formula
  version, dimensions, filters, units, precision, and caveats.
- Make reruns with identical input and governed versions byte-equivalent.
- Never fabricate metrics, forecast, apply customer-defined formulas, or emit generic non-retail
  analysis.

## Stable contract

`FactPackage` is immutable after publication and is the only numerical source for narrative,
charts, PDF, and Excel. A new input, mapping, formula, or correction creates a new version.

The five retained and recorded items above change the package's published shape, so they move it to
`rra004.package.v2`. The version bump carries approval here rather than arriving as an
implementation detail.

## Verification

Golden-dataset tests cover KPI answerability, conditional metrics, time and dimension aggregates,
rounding, reconciliation, deterministic reruns, refusal, provenance, and citation integrity.

This specification is draft and does not authorize product implementation.
